# Отчёт по ЛР 1

**ФИО:** Викулов Петр · **Группа:** ИУ3-32Б · **Модуль:** `32B-Vikulov`

Решено 15 задач, **30 баллов** (нужно ≥ 12):

| Раздел | Задачи | Баллы |
|--------|--------|-------|
| 1. Линейный поиск | 1, 2, 12 | 3 × 1 = 3 |
| 2. Сортировка | 13, 19, 20 | 3 × 2 = 6 |
| 3. Арифметика и статистика | 33, 34, 35 | 3 × 2 = 6 |
| 4. Преобразование массивов | 38, 42, 46 | 3 × 2 = 6 |
| 5. Матрицы | 53, 57, 60 | 3 × 3 = 9 |

Асимптотика каждой задачи — в [`asymptotics.md`](asymptotics.md).

## Структура

```
src/main/java/ru/bmstu/lab1/
├── common/        InputReader (чтение чисел/массивов/матриц), ConsoleIo (обвязка stdin/stdout)
└── task_NN/       по одному классу на задачу: чистый метод решения + main для консоли
```

Логика решения отделена от ввода-вывода: тесты вызывают метод решения напрямую, а `main` проверяется
отдельным тестом с подменой `System.in` / `System.out` (`ConsoleRunner`).

### Формат ввода
Массив: `n`, затем `n` чисел. Матрица: `n m`, затем `n` строк по `m` чисел. Дополнительные параметры
(`x`, `s`, `k`, второй массив, запросы) идут после массива. Разделители — любые пробелы и переводы строк.

## Идеи решений и выбор структур данных

| № | Идея | Почему так |
|---|------|------------|
| 1, 2 | Один линейный проход | Быстрее `O(n)` нельзя: нужно просмотреть каждый элемент |
| 12 | `HashMap` «значение → последний индекс» | Проверка «есть ли пара для `i`» за `O(1)` вместо перебора `O(n²)`; последний индекс сразу говорит, есть ли подходящий `j > i` |
| 13 | Сортировка выбором | Требование условия; минимальное число обменов (`≤ n − 1`) |
| 19 | Два указателя | Используем отсортированность входа — `O(n + m)`; `<=` делает слияние устойчивым |
| 20 | Массив счётчиков со сдвигом на `min` | Работает с отрицательными числами; ограничение диапазона защищает от `OutOfMemoryError` |
| 33 | Сортировка слиянием с подсчётом | Требование `O(n log n)`; ответ в `long`, т.к. до `~5·10⁹` при `n = 10⁵` |
| 34 | Алгоритм Кадане | `O(n)`, корректно для массива из одних отрицательных чисел |
| 35 | Массив префиксных сумм `long[n + 1]` | Фиктивный `prefix[0] = 0` убирает отдельный случай `l = 0` |
| 38 | Тройной разворот | `O(1)` доп. памяти; сдвиг нормализуется `((k mod n) + n) mod n` |
| 42 | Бинарный поиск верхней границы | Требование условия; равный элемент вставляется после существующих |
| 46 | Отсортированный массив уникальных значений + бинарный поиск | Гарантированные `O(n log n)` и компактная память, в отличие от `TreeMap`/`HashMap` |
| 53 | Предпосчёт минимумов строк и максимумов столбцов | `O(nm)` вместо `O(nm(n + m))` |
| 57 | Четыре сужающиеся границы | Проверки `top < bottom` и `left < right` убирают повторы для одной строки/столбца |
| 60 | Итеративный DFS с явным стеком `int[]` | Рекурсивный DFS падает со `StackOverflowError` на большой сплошной области; клетка кодируется числом `r·m + c` |

## Тесты

84 теста (JUnit), **покрытие строк 99,4 %, ветвлений 100 %** (JaCoCo: `mvn test`, отчёт в
`target/site/jacoco/index.html`). Для каждой задачи есть тесты на обычный случай, граничные случаи и запуск через консоль.

### Примеры важных ручных тестов

| Задача | Вход | Ожидается | Почему важно |
|--------|------|-----------|--------------|
| 12 | `[1, 2, 4, 5]`, `s = 6` | `0 3` | Две пары; проверяет, что выбирается наименьший `i`, а не первая найденная |
| 12 | `[3, 1]`, `s = 6` | `-1 -1` | Элемент нельзя складывать сам с собой |
| 20 | `[MIN_VALUE, MAX_VALUE]` | исключение | Диапазон `2³²` — защита от выделения гигантского массива |
| 33 | `n = 10⁵`, по убыванию | `4 999 950 000` | Ответ не помещается в `int` |
| 33, 13, 20 | случайные массивы | совпадение с эталоном | Сверка с перебором `O(n²)` / `Arrays.sort` |
| 34 | `[-3, -1, -2]` | `-1` | Все отрицательные — частая ошибка «ответ 0» |
| 38 | `k = 7` при `n = 5`; `k = -1` | как `k = 2`; сдвиг вправо | Сдвиг больше длины и отрицательный |
| 57 | `1 × 3` и `3 × 1` | `1 2 3` | Без проверок границ элементы выводятся дважды |
| 60 | Шахматный узор `3 × 3` | `5` | Диагональ не считается связью |
| 60 | `1000 × 1000` из единиц | `1` | Проверка отсутствия переполнения стека |
