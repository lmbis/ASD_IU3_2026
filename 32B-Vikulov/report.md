## Структура

```
src/main/java/ru/bmstu/lab1/
├── common/        InputReader (чтение чисел/массивов/матриц), ConsoleIo (обвязка stdin/stdout)
└── task_NN/
    ├── <Решение>.java   метод решения + main для консоли
    └── report.md        отчёт по задаче
src/test/java/ru/bmstu/lab1/
├── common/        тест чтения ввода, ConsoleRunner (подмена System.in / System.out в тестах)
└── task_NN/<Решение>Test.java
```

Логика решения отделена от ввода-вывода: тесты вызывают метод решения напрямую, а `main` проверяется
отдельным тестом с подменой стандартных потоков.

### Формат ввода
Массив: `n`, затем `n` чисел. Матрица: `n m`, затем `n` строк по `m` чисел. Дополнительные параметры
(`x`, `s`, `k`, второй массив, запросы) идут после массива. Разделители — любые пробелы и переводы строк.
Точный формат и пример запуска — в отчёте каждой задачи.

## Тесты

84 теста (JUnit), **покрытие строк 99,4 %, ветвлений 100 %** (JaCoCo: `mvn test`, отчёт в
`target/site/jacoco/index.html`). Для каждой задачи есть тесты на обычный случай, граничные случаи и запуск
через консоль; где это возможно — сверка со стандартной реализацией или перебором на случайных данных.
Что проверяет каждый тест и почему он важен — в таблице «Тесты» отчёта задачи.
