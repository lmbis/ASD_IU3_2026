# Задача 13. Сортировка выбором

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 2 · **Решение:** [`SelectionSort.java`](SelectionSort.java) · **Тесты:** [`SelectionSortTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_13/SelectionSortTest.java)

## Условие

**Вход:** массив из n целых чисел.  
**Выход:** массив, отсортированный по неубыванию.  
**Требование:** реализовать сортировку выбором вручную, без использования встроенных функций сортировки.  
**Сложность:** базовая

## Формат ввода-вывода

- **Ввод:** `n`, затем `n` целых чисел. Числа разделяются пробелами или переводами строк.
- **Вывод:** массив по неубыванию.

Пример запуска:

```text
ввод:
3
3 1 2

вывод:
1 2 3
```

## Идея решения и выбор структуры данных

Сортировка выбором, реализованная вручную, как требует условие. Массив делится на отсортированный префикс
`[0, i)` и неотсортированный суффикс `[i, n)`. На каждом шаге в суффиксе ищется минимум, и он меняется местами
с `a[i]`. После шага `i` префикс `[0, i]` содержит `i + 1` наименьших элементов в правильном порядке.

Сортировка идёт на месте и не требует дополнительной памяти. Особенность алгоритма: делается не больше
`n − 1` обменов. Это минимум среди простых сортировок, хотя сравнений всегда `n(n − 1)/2`.

Алгоритм неустойчив, но для массива целых чисел это не важно: равные числа неразличимы.

## Асимптотика — [`SelectionSort.java`](SelectionSort.java#L22-L34)

```java
23:        for (int i = 0; i < values.length - 1; i++) {
24:            int minIndex = i;
25:            for (int j = i + 1; j < values.length; j++) {
26:                if (values[j] < values[minIndex]) {
27:                    minIndex = j;
28:                }
29:            }
30:            int tmp = values[i];
31:            values[i] = values[minIndex];
32:            values[minIndex] = tmp;
33:        }
```

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| 23, 24, 30–32 | O(1) | n − 1 | O(n) |
| 25–27 (тело внутреннего цикла) | O(1) | Σ_{i=0}^{n−2} (n − 1 − i) = n(n − 1)/2 | O(n²) |

**Время:** `T(n) = n(n − 1)/2 · c₁ + (n − 1) · c₂ = O(n²)`. Число сравнений в строке 26 не зависит от входа,
поэтому лучший случай тоже `Θ(n²)`. Обменов (строки 30–32) ровно `n − 1`.
**Память:** `i, j, minIndex, tmp` — `O(1)`, сортировка на месте.
