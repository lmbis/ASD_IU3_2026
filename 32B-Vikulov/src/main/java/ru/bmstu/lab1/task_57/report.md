# Задача 57. Спиральный обход матрицы

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 3 · **Решение:** [`SpiralTraversal.java`](SpiralTraversal.java) · **Тесты:** [`SpiralTraversalTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_57/SpiralTraversalTest.java)

## Условие

**Вход:** матрица n x m из целых чисел.  
**Выход:** элементы матрицы, обойдённые по спирали от левого верхнего угла по часовой стрелке.  
**Сложность:** средняя

## Формат ввода-вывода

- **Ввод:** `n m`, затем матрица `n × m`. Числа разделяются пробелами или переводами строк.
- **Вывод:** элементы по спирали от левого верхнего угла по часовой стрелке.

Пример запуска:

```text
ввод:
2 2
1 2
3 4

вывод:
1 2 4 3
```

## Идея решения и выбор структуры данных

Хранятся четыре границы ещё не пройденной области: `top`, `bottom`, `left`, `right`. Один виток спирали:

1. верхняя строка слева направо, затем `top` сдвигается вниз;
2. правый столбец сверху вниз, затем `right` сдвигается влево;
3. нижняя строка справа налево, затем `bottom` сдвигается вверх;
4. левый столбец снизу вверх, затем `left` сдвигается вправо.

Цикл идёт, пока область не пуста (`top ≤ bottom` и `left ≤ right`).

Главная тонкость — проверки `top < bottom` перед шагом 3 и `left < right` перед шагом 4. Если от области
осталась одна строка или один столбец, шаги 1–2 уже вывели все её элементы, и без проверок они вывелись бы
повторно. Ответ записывается в заранее выделенный массив длины `n·m`. Отдельный массив «посещённых» клеток не
нужен, его роль играют границы.

## Асимптотика — [`SpiralTraversal.java`](SpiralTraversal.java#L27-L60)

```java
31:        int[] result = new int[matrix.length * matrix[0].length];
37:        while (top <= bottom && left <= right) {
38:            for (int j = left; j <= right; j++) {
39:                result[k++] = matrix[top][j];
40:            }
41:            for (int i = top + 1; i <= bottom; i++) {
42:                result[k++] = matrix[i][right];
43:            }
44:            if (top < bottom) {
45:                for (int j = right - 1; j >= left; j--) {
46:                    result[k++] = matrix[bottom][j];
47:                }
48:            }
49:            if (left < right) {
50:                for (int i = bottom - 1; i > top; i--) {
51:                    result[k++] = matrix[i][left];
52:                }
53:            }
54:            top++;
55:            bottom--;
56:            left++;
57:            right--;
58:        }
```

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| 31 | O(nm) | 1 | O(nm) |
| 39, 42, 46, 51 — запись в ответ | O(1) | суммарно ровно n · m | O(nm) |
| 37, 44, 49, 54–57 — служебные строки витка | O(1) | ⌈min(n, m)/2⌉ витков | O(min(n, m)) |

Каждая запись в строках 39/42/46/51 увеличивает `k` на 1. Проверки в строках 44 и 49 гарантируют, что ни
одна клетка не записывается дважды, поэтому `k` дойдёт ровно до `nm`. Витков `⌈min(n, m)/2⌉`, потому что
каждый виток сдвигает обе пары границ (строки 54–57).
**Время:** `O(nm) + O(min(n, m)) = O(nm)`.
**Память:** ответ `result` размера `nm` и четыре границы `O(1)`.
