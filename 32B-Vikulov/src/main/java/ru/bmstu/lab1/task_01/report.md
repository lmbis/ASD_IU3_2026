# Задача 1. Максимум и минимум

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 1 · **Решение:** [`MinMax.java`](MinMax.java) · **Тесты:** [`MinMaxTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_01/MinMaxTest.java)

## Условие

**Вход:** массив из n целых чисел.  
**Выход:** минимальный и максимальный элементы массива.  
**Ограничения:** 1 < n < 10^5.  
**Сложность:** базовая

## Формат ввода-вывода

- **Ввод:** `n`, затем `n` целых чисел. Числа разделяются пробелами или переводами строк.
- **Вывод:** минимум и максимум через пробел.

Пример запуска:

```text
ввод:
4
4 1 3 2

вывод:
1 4
```

## Идея решения и выбор структуры данных

Достаточно одного прохода по массиву. Заводим `min` и `max`, равные первому элементу, и сравниваем с ними
каждый следующий элемент.

Начальное значение берётся из массива, а не `Integer.MAX_VALUE` / `MIN_VALUE`. Так результат всегда является
элементом массива, и не нужно отдельно обрабатывать «пустые» начальные значения. Дополнительная структура
данных не нужна: хватает двух переменных.

**Граничные случаи:** все элементы равны (min = max); значения на границах `int`; пустой массив, на нём
выбрасывается `IllegalArgumentException`, потому что по условию `n > 1`, а молча вернуть «что-то» хуже.

## Асимптотика — [`MinMax.java`](MinMax.java#L23-L34)

```java
24:        if (values.length == 0) {
25:            throw new IllegalArgumentException("Array must not be empty");
26:        }
27:        int min = values[0];
28:        int max = values[0];
29:        for (int value : values) {
30:            min = Math.min(min, value);
31:            max = Math.max(max, value);
32:        }
33:        return new int[] {min, max};
```

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| 24, 27, 28, 33 | O(1) | 1 | O(1) |
| 29 (заголовок цикла) | O(1) | n + 1 | O(n) |
| 30, 31 | O(1) | n | O(n) |

**Время:** `T(n) = O(1) + O(n) + O(n) = O(n)`.
**Память:** переменные `min`, `max` и массив ответа из двух элементов — `O(1)`.
