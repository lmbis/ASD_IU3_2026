# Задача 35. Префиксные суммы

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 2 · **Решение:** [`PrefixSums.java`](PrefixSums.java) · **Тесты:** [`PrefixSumsTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_35/PrefixSumsTest.java)

## Условие

**Вход:** массив из n целых чисел и q запросов вида [l, r] — диапазон индексов.  
**Выход:** для каждого запроса — сумму элементов с индексами от l до r включительно.  
**Требование:** предпосчёт префиксных сумм, затем O(1) на запрос.  
**Сложность:** средняя

## Формат ввода-вывода

- **Ввод:** `n`, `n` чисел, `q`, затем `q` пар `l r` (индексы с нуля, включительно). Числа разделяются пробелами или переводами строк.
- **Вывод:** для каждого запроса сумма `a[l..r]` на отдельной строке.

Пример запуска:

```text
ввод:
4
1 2 3 4
3
0 3
1 2
3 3

вывод:
10
5
4
```

## Идея решения и выбор структуры данных

Предпосчёт префиксных сумм: `prefix[i]` — сумма первых `i` элементов, `prefix[0] = 0`. Тогда сумма на отрезке
`sum(l, r) = prefix[r + 1] − prefix[l]` считается одним вычитанием, за `O(1)`, как требует условие.

Решения по реализации:
- массив `prefix` имеет длину **`n + 1`**. Фиктивный ноль в начале убирает отдельный случай `l = 0`;
- задача оформлена как класс с состоянием: конструктор делает предпосчёт, метод `sum` отвечает на запрос.
  Так предпосчёт явно выполняется один раз на все запросы;
- тип `long[]`: сумма до `10⁵` чисел порядка `10⁹` не помещается в `int`;
- некорректный отрезок (`l < 0`, `r ≥ n`, `l > r`) даёт понятное исключение, а не неверный ответ.

## Асимптотика — [`PrefixSums.java`](PrefixSums.java#L23-L43)

```java
24:        prefix = new long[values.length + 1];
25:        for (int i = 0; i < values.length; i++) {
26:            prefix[i + 1] = prefix[i] + values[i];
27:        }
...
39:        if (left < 0 || right >= prefix.length - 1 || left > right) {
40:            throw new IndexOutOfBoundsException("Invalid range [" + left + ", " + right + "]");
41:        }
42:        return prefix[right + 1] - prefix[left];
```

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| 24 | O(n) | 1 | O(n) |
| 25–26 — предпосчёт | O(1) | n | O(n) |
| 39, 42 — один запрос | O(1) | 1 на запрос | O(1) |

**Время:** предпосчёт `O(n)`, каждый запрос `O(1)`, всего на `q` запросов `O(n + q)`.
Без префиксных сумм каждый запрос суммировал бы до `n` элементов, итого `O(n · q)`.
**Память:** массив `prefix` длины `n + 1`, `O(n)`.
