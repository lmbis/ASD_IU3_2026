# Задача 2. Индекс первого вхождения

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 1 · **Решение:** [`FirstOccurrence.java`](FirstOccurrence.java) · **Тесты:** [`FirstOccurrenceTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_02/FirstOccurrenceTest.java)

## Условие

**Вход:** массив из n целых чисел и число x.  
**Выход:** индекс первого элемента, равного x. Если такого нет — вывести `-1`.  
**Сложность:** базовая

## Формат ввода-вывода

- **Ввод:** `n`, затем `n` целых чисел, затем `x`. Числа разделяются пробелами или переводами строк.
- **Вывод:** индекс первого элемента, равного `x`, или `-1`.

Пример запуска:

```text
ввод:
5
1 2 3 3 3
3

вывод:
2
```

## Идея решения и выбор структуры данных

Линейный поиск слева направо с выходом на первом совпадении. Массив не отсортирован, поэтому бинарный поиск
неприменим, а любой элемент может оказаться искомым. В худшем случае нужно просмотреть все `n` элементов.

Значение «не найдено» вынесено в константу `NOT_FOUND = -1`, чтобы не было «магического числа».

**Граничные случаи:** элемент стоит первым (ответ 0); элемент повторяется (нужен именно первый индекс);
элемента нет (`-1`).

## Асимптотика — [`FirstOccurrence.java`](FirstOccurrence.java#L26-L33)

```java
27:        for (int i = 0; i < values.length; i++) {
28:            if (values[i] == target) {
29:                return i;
30:            }
31:        }
32:        return NOT_FOUND;
```

| Строки | Стоимость | Раз (худший случай) | Вклад |
|--------|-----------|---------------------|-------|
| 27 | O(1) | n + 1 | O(n) |
| 28 | O(1) | n | O(n) |
| 29 или 32 | O(1) | 1 | O(1) |

Худший случай — элемента нет или он последний: строка 28 выполняется `n` раз.
Лучший случай — `a[0] = x`, тогда `O(1)`.
**Время:** `O(n)`. **Память:** только счётчик `i`, `O(1)`.
