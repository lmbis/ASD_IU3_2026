# Задача 19. Объединение двух отсортированных массивов

**Студент:** Викулов Петр, ИУ3-32Б · **ЛР 1** · **Баллы:** 2 · **Решение:** [`MergeSorted.java`](MergeSorted.java) · **Тесты:** [`MergeSortedTest.java`](../../../../../../test/java/ru/bmstu/lab1/task_19/MergeSortedTest.java)

## Условие

**Вход:** два массива, каждый отсортирован по неубыванию; размеры n и m.  
**Выход:** один отсортированный массив — результат слияния.  
**Требование:** O(n + m).  
**Сложность:** средняя

## Формат ввода-вывода

- **Ввод:** `n`, `n` чисел, `m`, `m` чисел (оба массива по неубыванию). Числа разделяются пробелами или переводами строк.
- **Вывод:** результат слияния по неубыванию.

Пример запуска:

```text
ввод:
2
-3 0
2
0 7

вывод:
-3 0 0 7
```

## Идея решения и выбор структуры данных

Метод двух указателей, тот же шаг, что и в сортировке слиянием. Указатели `i` и `j` стоят на текущих
наименьших непросмотренных элементах обоих массивов. Меньший из двух переносится в результат, и его указатель
сдвигается. Когда один массив заканчивается, остаток другого копируется как есть: он уже отсортирован.

Склеить массивы и отсортировать заново стоило бы `O((n + m) log(n + m))`. Здесь используется то, что входы
уже отсортированы, и получается `O(n + m)`, как требует условие.

Сравнение `<=` (а не `<`) при равенстве берёт элемент из **левого** массива, поэтому слияние устойчиво.

**Граничные случаи:** один из массивов пуст; одинаковые элементы в обоих массивах.

## Асимптотика — [`MergeSorted.java`](MergeSorted.java#L24-L40)

```java
25:        int[] result = new int[left.length + right.length];
29:        while (i < left.length && j < right.length) {
31:            result[k++] = left[i] <= right[j] ? left[i++] : right[j++];
32:        }
33:        while (i < left.length) {
34:            result[k++] = left[i++];
35:        }
36:        while (j < right.length) {
37:            result[k++] = right[j++];
38:        }
```

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| 25 — выделение и обнуление массива | O(n + m) | 1 | O(n + m) |
| 31 | O(1) | t₁ | |
| 34 | O(1) | t₂ | |
| 37 | O(1) | t₃ | |

Каждое выполнение строк 31, 34 или 37 увеличивает `k` ровно на 1, а `k` растёт от `0` до `n + m`.
Отсюда `t₁ + t₂ + t₃ = n + m`.
**Время:** `O(n + m) + (n + m) · O(1) = O(n + m)`.
**Память:** массив `result` длины `n + m` (это ответ), остальное `O(1)`.
