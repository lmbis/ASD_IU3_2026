# Расчёт асимптотики — ЛР 1

Обозначения: `n` — длина массива (для матриц `n` строк и `m` столбцов), `q` — число запросов,
`k` — диапазон значений (`max - min + 1`). «Доп. память» — без учёта входа; память под ответ указана отдельно,
если он создаётся новым массивом.

## Подробные выкладки для нетривиальных случаев

### Задача 12
Наивное решение перебирает все пары: `n(n-1)/2 = O(n²)`. В решении:
1. Таблица «значение → последний индекс»: `n` вставок по `O(1)` в среднем.
2. Для `i = 0, 1, …` проверяем `last[s - a[i]] > i` за `O(1)`. Первое подходящее `i` минимально.
3. Для найденного `i` идём вправо до первого `a[j] = s - a[i]` — не больше `n` шагов, выполняется один раз.

Итого `O(n) + O(n) + O(n) = O(n)`. Худший случай хеш-таблицы — `O(n)` на операцию, но для `HashMap<Long, …>`
с равномерным хешем это практически не встречается.

### Задача 33
Рекурсия делит отрезок пополам, слияние двух половин суммарной длины `len` выполняется за `O(len)`,
и вместе с ним считаются инверсии «между половинами» (`mid - i` за одно сравнение).
На каждом из `log₂ n` уровней рекурсии суммарная длина слияний равна `n` ⇒ `O(n log n)`.

### Задача 20
Если `k` много больше `n` (например, значения до `10⁹`), алгоритм становится неэффективным по памяти,
поэтому введено ограничение `MAX_RANGE = 10⁷` и при большем диапазоне выбрасывается исключение.
